# CORE JAVA PROGRAMS - JAVA FULL STACK 

# PROJECT OVERVIEW:

This repository contains a collection of Core Java programs and practical coding exercises developed during my Java Full Stack Developer training at TNS India Foundation.

The project focuses on strengthening Java programming fundamentals and understanding Object-Oriented Programming (OOP) concepts through hands-on implementation.

# DESCRIPTION:

This repository demonstrates practical implementations of Core Java concepts, including variables, data types, operators, conditional statements, loops, arrays, strings, methods, classes, objects, constructors, inheritance, polymorphism, encapsulation, abstraction, and exception handling.

Each program focuses on understanding Java concepts, improving logical thinking, and developing problem-solving skills through coding practice.

# WHAT THIS APPLICATION DOES:

Demonstrates fundamental Java programming concepts through practical examples.

Implements conditional statements and loops to solve basic programming problems.

Uses arrays and strings to perform data manipulation operations.

Demonstrates methods, classes, objects, and constructors.

Implements OOP principles such as inheritance, polymorphism, encapsulation, and abstraction.

Practises exception handling to manage runtime errors.

Helps develop logical thinking, debugging, and problem-solving skills.
